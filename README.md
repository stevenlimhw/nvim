# 🛠️ Neovim Configuration

> My personalized Neovim setup using `lazy.nvim`, modular plugin configs, written in Lua.

[![Neovim](https://img.shields.io/badge/Neovim-0.9+-blue?logo=neovim)](https://neovim.io/)
![MacOS](https://img.shields.io/badge/Platform-macOS-lightgrey?logo=apple)

## Summary

This is the modular Neovim configuration, which includes:

- `lazy.nvim` is used as the plugin manager,
- structured Lua configuration in the `lua/` directory,
- and an optional `.tmux.config` to be copied to `~/.tmux.config` on macOS.


## Adding a Plugin
1. **Declare the plugin**

    Add the plugin's GitHub repo to `lua/config/plugins.lua`. For example:
    ```
    {
      "nvim-telescope/telescope.nvim",
      dependencies = { "nvim-lua/plenary.nvim" }
    }
    ```
2. **Create plugin config file**

    Add a lua file in `lua/plugins/`, e.g. `telescope.lua` and configure the plugin.
3. **Don't forget to require it during initialization**

    In `lua/plugins/init.lua`, add the require statement. For example:
    ```
    require("plugins.telescope")
    ```

4. In the future, customization of the plugin configuration can be done in the specific plugin file in `lua/plugins/` (e.g. `telescope.lua`). For details on how to do this, you can refer to the specific plugin's github documentation.

## Changing the colorscheme
1. Declare the plugin by adding in the github repo into `lua/config/plugins.lua`. Set the `priority` setting as 1000, and change the other colorschemes' priority to 999.
    ```
      {
        "ellisonleao/gruvbox.nvim",
        priority = 1000,
        config = true,
        opts = ...
      },
    ```
1. Add in the configuration (refer to the specific plugin's github repo) and add it to `lua/plugins/colorscheme.lua`.
1. Don't forget to add the following line at the bottom of `lua/plugins/colorscheme.lua`. For instance, if I want to set `gruvbox` as the active colorscheme:
    ```
    vim.cmd([[colorscheme gruvbox]])
    ```

## Task Management with Orgmode
Recently started using `nvim-orgmode/orgmode` for organizing tasks and deadlines in neovim. Really liking it so far (as of April 2025).
### Capture Templates
- Currently, I have two capture templates. These can be configures in `lua/config/plugins.lua` in the config function.
    1. the default `Task` with `t` toggle; the notes file path is at `~/sync/org/main.org`
    1. `Journal` with `j` toggle; the journal file path is dynamically set based on month at `~/sync/org/journal/%<%Y-%m>.org`.
### Viewing tasks
- **Agenda Mode.** Inside neovim, use `<leader>oa`, then press `a` to open the agenda. Within the agenda, you can use `g?` command to list out the available commands.
### Adding a new entry
- **Adding a Task.** Inside neovim, use `<leader>oc` then press `t` to create a new task. To add a deadline, press `<leader>oid` and select the date on the calendar interface that pops up. After you are done, then press `:wq` to save and quit.
- **Adding a Journal entry.** Inside neovim, use `<leader>oc` then press `j`. After you are done, then press `:wq` to save and quit. Each journal entry will be saved in a file corresponding to the month in which you added the entry.
